# Contributing to Planward

Install Node 22+ and pnpm, then run `pnpm install`. Keep domain behaviour in `src/core`,
views in `src/components` and `src/app`, and persistence behind server modules.

Open an issue before proposing work outside the project’s non-goals: portfolio management,
invoicing, per-ticket time tracking, configurable workflows, fine-grained permissions, or
an integration catalogue.

Contributions are accepted under the Developer Certificate of Origin. Sign commits with:

```text
Signed-off-by: Your Name <you@example.com>
```
